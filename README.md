

# Grain App

Grain App is a Flutter/Dart personal expense tracker developed as part of the INFO1111 Advanced Self-Learning Assignment.

The project explores how generative AI tools can support software product development, including product planning, UI prototyping, Flutter implementation, debugging, testing, and iterative improvement.

## Project Concept

The name "Grain" represents something small but valuable. Money is accumulated little by little, like grains. The app is designed to help users record daily expenses, understand spending habits, and reflect on small repeated purchases.

## Core Features

- Add and manage expense records
- View recent transactions
- Calendar-based spending view
- Monthly and yearly financial statistics
- Spending insights
- Theme and accent colour settings
- CSV export support

## Development Workflow

This project follows an AI-assisted development workflow:

1. Product planning with a mini PRD
2. UI prototyping with Stitch
3. Flutter/Dart implementation with AI coding assistance
4. GitHub version control and milestone commits
5. Manual testing and feature refinement
6. Reflection on the learning process
