# grain_app


Grain App is a lightweight personal expense tracker built in one day by Gemini 3, during a six-month-long pre-university holiday.


While algorithms are important, they can get… a bit dry. Out of boredom (and curiosity), i try ai coding, that’s how Grain was born :)

This app is made for my own use, specifically to record daily expenses during my study-abroad life in AUS.
What does it do?

Manually record expense amounts and descriptions
- Track daily spending during my study-abroad life in AUS
- Analyse daily spending
- Export data as an Excel financial report
   - Mostly so I can send it to my parents
    - Yes, this feature is mandatory :)

 “Grain” represents something small but valuable.
Money isn’t easy to earn — it’s accumulated little by little, like grain.
This app is a reminder that every expense matters, no matter how small.

Who is this for?
... only me
